# Cupertino Soft 0.4.1 — independent release

First release from the independent Cupertino Soft repository, with its own original appearance-only stylesheet. This repository has no upstream fork ancestry or copied assets.

- Soft gray interface (#EBEBED) with a near-white note surface (#FAFAFA).
- Readable #333338 body text, discreet #FF3B30 accents and pale red selection.
- Red H1–H4 headings, subdued metadata, zebra-striped tables and Markdown styling.
- Coordinated dark-mode variables.
- Linux-friendly native tabs, ribbons, titlebar and window controls, left to Obsidian.
- Best-effort orange #FF9500 wavy spellcheck underline, with no change to dictionaries.
- Screenshots of the theme running in Obsidian for Linux.
- Linux installer supporting Obsidian Flatpak and .deb without changing vault data.

Assets: `theme.css` and `manifest.json`.

Historical inspiration: [Cupertino](https://github.com/svnaxis/obsidian-cupertino) by svnaxis (MIT). No copied code or graphical assets.
