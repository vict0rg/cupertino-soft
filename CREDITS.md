# Credits and provenance

**Cupertino Soft** — original appearance-only CSS, scripts and documentation by **Victor Gianordoli (vict0rg)**, 2026, MIT.

## Visual inspiration

- [Cupertino for Obsidian](https://github.com/svnaxis/obsidian-cupertino) by **svnaxis** (MIT) inspired the calm gray native-feeling navigation and the Cupertino name.
- [Cupertino for Zotero](https://github.com/shenghuang-123/cupertino-for-zotero) (MIT) inspired the shared system-red palette of related reading tools.
- [Notation](https://github.com/deathau/Notation-for-Obsidian) (The Unlicense), [Typewriter](https://github.com/crashmoney/obsidian-typewriter) (GPL-3.0), [Shimmering Focus](https://github.com/chrisgrieser/shimmering-focus) (MIT), and [Olivier's Theme](https://github.com/OlivierPS/Olivier-s-Theme) (MIT) were visual design references only.

No source code, fonts, graphical assets, or bundled libraries were imported from these reference projects.

## Historical note

Earlier design experiments took place in a [fork of Cupertino](https://github.com/vict0rg/cupertino-obsidian-soft-theme). This repository is not a fork: it starts with its own initial commit containing the newly written Cupertino Soft stylesheet and documentation. No upstream Git history, `src/`, `img/`, or `cupertino.png` is included.

## Companion theme

[Cupertino Zotero Soft Theme](https://github.com/vict0rg/cupertino-zotero-soft-theme) is maintained and installed independently; no Zotero extension code is bundled in Cupertino Soft.

All third-party project names are credited for context, not endorsement.
